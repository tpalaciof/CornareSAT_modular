COMANDOS PARA LA ESP32

SI NO ESTÁ INSTALADO EL FIRMWAREORIGINAL

1. Abre la carpeta firmware de pluviógrafo y en la terminal 

Copy-Item .\secrets.ini.example .\secrets.ini
notepad .\secrets.ini

# Copy to firmware/secrets.ini and replace placeholders with out-of-repo values.
# Markers: <MQTT_USER>, <MQTT_PASSWORD>, <STATION_CODE>.
# This example is safe to commit. Never put real credentials in Git, logs, or handoffs.

[secrets]
build_flags =
  -DMQTT_USER=\"geoalertas\"
  -DMQTT_PASSWORD=\"o9keYGujDJOxfQRF\"
  -DSTATION_CODE=\"667\"


& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" run -e estacion-v1 -t upload --upload-port COM3

2. Abre la carpeta Arranque_dual_GW_ESP32_rev1_2

Si no se tiene Python instalado: 

& "$env:USERPROFILE\.platformio\penv\Scripts\python.exe" -m venv .venv-selector

LUEGO
.\.venv-selector\Scripts\python.exe -m pip install "esptool>=4.7,<5"

.\.venv-selector\Scripts\python.exe selector.py --puerto COM3 instalar --bootloader binarios/bootloader.bin --tabla binarios/partition-table.bin --xbee binarios/xbee.bin --respaldo arranque_original_COM3.bin

La confirmación esperada es Instalado. Selección inicial NORMAL.


Para pasar a modo XBee, ejecuta en esa misma terminal, con el monitor serie cerrado:
.\.venv-selector\Scripts\python.exe selector.py --puerto COM3 xbee

Luego abre el monitor y pulsa EN una vez para ver el nuevo arranque:
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" device monitor --port COM3 --baud 115200 --echo


En el monitor que ya tienes abierto, escribe estas dos líneas, pulsando Enter después de cada una:
config codigo 667
reiniciar
